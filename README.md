
# 🌐 Personal Portfolio Website

## 📌 About the Project
This is a simple personal portfolio website developed using HTML and CSS. The website provides basic personal information and a contact section.

## 📄 Pages Included

### 1. Home Page
- Displays personal name.
- Shows professional title.
- Provides a simple introduction.

### 2. Contact Page
- Includes a contact form.
- Name field.
- Email field.
- Message field.
- Submit button.
- Social media links.

## 🛠️ Technologies Used
- HTML5
- CSS3

## 📂 Project Structure

```text
Portfolio/
│
├── index.html
├── contact.html
├── style.css
└── README.md
```

## 🚀 How to Run
1. Clone or download the repository.
2. Open the project folder.
3. Open `index.html` in your web browser.
4. Navigate to the Contact page.
